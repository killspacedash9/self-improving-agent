How the loop works

  1. You type a request here.
  2. It becomes a GitHub issue labeled agent-request.
  3. The Self-Improve workflow wakes up and asks DeepSeek for a plan.
  4. The agent edits its own code, runs the tests, and commits.
  5. Pages re-deploys itself — and the journal below updates.
